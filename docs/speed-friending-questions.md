# Speed friending questions

480 questions: every level (A1 to C2) × 8 fun themes × 10. Each student gets their own
question to ask their partner, and a new one each round. The list is in `src/data/fun-questions.ts`
and (once checked) the `friending_questions` table, where questions can be edited or switched off.
